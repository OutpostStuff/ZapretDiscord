>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как потенциально опасные или относящиеся к хакерским инструментам. В результате файл может быть удалён и помещён в карантин. В обнаружении обычно присутствует название `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса или отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Исключение предпочтительнее при точной настройке, но если вы не уверены в своих действиях, отключите обнаружение PUA.

## ⚙️Использование

1. Сначала активируйте безопасный DNS (Secure DNS).
    * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию".
    * В Firefox откройте настройки "DNS через HTTPS", установите режим "Персональный", затем выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы - инструкция доступна [по этой ссылке](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот вариант рекомендуется.
    * Владельцам роутеров Keenetic нужно включить настройку "Транзит запросов". При отключённой опции Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/OutpostStuff/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не требуется.

4. Извлеките файлы в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите нужный сценарий:
    * Чтобы найти подходящую стратегию, откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.
    * Для добавления стратегии в автозапуск перейдите в **`service.bat`** -> `Install Service` и выберите подходящий вариант.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегий.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую для своей системы**.

- [**`service.bat`**](./service.bat) - управление автозапуском и дополнительными возможностями:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск Windows (services.msc).</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из списка служб.
  - **`Check Status`** - просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** - включение или отключение обхода для игр и других сервисов, работающих с UDP и TCP-портами выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  Текущее состояние отображается в скобках.
  - **`IPSet Filter`** - выбор режима обхода сервисов, перечисленных в `ipset-all.txt`.  
  Опция пригодится при проверке ресурса, который без zapret открывается, а с ним перестаёт работать.  
  В скобках показывается текущий режим:
    - `none` - IP-адреса не проходят проверку
    - `loaded` - проверяется наличие IP в списке
    - `any` - фильтр применяется к любому IP
  - **`Auto-Update Check`** - включение или отключение автоматической проверки обновлений.
  - **`Replace active fakes`** - замена выбранного фейка на другой файл из каталога `bin`.
  - **`Update IPSet List`** - загрузка актуального `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** - обновление hosts <ins>для восстановления веб-версии Telegram и подключения к голосовым чатам Discord.</ins>
  - **`Check for Updates`** - ручная проверка наличия обновлений.
  - **`Run Diagnostics`** - поиск распространённых причин, из-за которых zapret может не запускаться или не работать.  
  В финале можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность приложения.
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/OutpostStuff/zapret-discord-youtube/issues/522).

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и запустите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Выделите и скопируйте весь текст из открытого блокнота.
  - Откройте файл `hosts` в созданной папке через текстовый редактор, запущенный от имени администратора.
  - Вставьте скопированное содержимое в конец файла `hosts` или замените прежнюю аналогичную запись.
  - Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранены.

#### Работа не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/OutpostStuff/tg-ws-proxy) либо с любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Работа стратегий со временем может прекращаться.**
> Обнаружение определённой стратегии может произойти не сразу: вариант, который некоторое время работал, позднее перестаёт работать.
> Здесь собраны разные стратегии обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и проверьте, не сообщает ли диагностика об ошибках.

- Проверьте, добавлен ли адрес нужного ресурса в списки доменов или IP-адресов.

- Испытайте другие стратегии, включая **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- Дополнительные сведения есть в [#765](https://github.com/OutpostStuff/zapret-discord-youtube/issues/765).

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и другие данные.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Затем запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их и в конце подтвердите действие клавишей Y.
- Удалите каталог zapret.
- Загрузите свежую версию [со страницы релизов](https://github.com/OutpostStuff/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу есть флажок разблокировки, установите его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новый каталог в корне диска, без пробелов и специальных символов.
- По очереди запускайте разные скрипты `general`. Проверяйте интернет-ресурсы; если выбранная стратегия не подходит, закройте программу через значок замка на панели задач и попробуйте следующую.
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service`.

### Не работает игра/приложение с включённым запретом

- Проверьте в `service.bat`, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Найдите имя службы командой в командной строке Windows. Открыть её можно через Win+R и `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройки [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Перезапустите проверку со всеми другими стратегиями, особенно если выбранный ранее вариант перестал работать.
- Также смотрите [#251](https://github.com/OutpostStuff/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен.
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить именно её.
- В `service.bat` откройте `Run Diagnostics` и выполните очистку кэша Discord.
- Снова проверьте приложение Discord после очистки кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, используйте её.
- Если Discord не открывается и в браузере, проверьте остальные стратегии. YouTube и Discord могут работать на разных вариантах.
- Дополнительное обсуждение: [#252](https://github.com/OutpostStuff/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/OutpostStuff/tg-ws-proxy).
- Либо подключитесь к бесплатному MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Начните с универсальной последовательности:
- обновите ipset через `service.bat` и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/OutpostStuff/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Оформите сообщение [здесь](https://github.com/OutpostStuff/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Новые адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** - домены, включая автоматически учитываемые поддомены;
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда сеть уже присутствует в `ipset-all.txt`, но отдельный домен фильтровать не следует;
- **`ipset-all.txt`** - IP-адреса и подсети;
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, исключённые из фильтрации.
  - Файлы **`*-user.txt`** будут автоматически созданы при первом запуске `zapret` или `service.bat`.
